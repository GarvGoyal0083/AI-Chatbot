🤖 AI Chatbot with Google Colab & Streamlit

Build and deploy an AI-powered chatbot entirely in **Google Colab** using **Streamlit** and **ngrok**. 🚀 No local setup required—just add your API key, run the notebook, and launch your chatbot with a public web URL.

---

✨ Features

* 🤖 AI-powered conversational chatbot
* ☁️ Runs completely on Google Colab
* 🎨 Interactive Streamlit interface
* 🌐 Public access using ngrok
* ⚡ Quick and beginner-friendly setup
* 🔑 Supports API key integration

---

🛠️ Tech Stack

* Python
* Google Colab
* Streamlit
* ngrok
* AI API (OpenAI/Gemini or compatible models)

---

🚀 Getting Started

1. Open the notebook in **Google Colab**.
2. Install the required dependencies.
3. Add your AI API key.
4. Run all notebook cells.
5. Open the generated **ngrok** URL.
6. Start chatting with your AI assistant!
